# موقع ALQUBTAN AGENCY

موقع ثابت بيتبني بـ Node من غير أي مكتبات خارجية.

## إعدادات Cloudflare Pages

- Build command: `node build.mjs`
- Build output directory: `dist`

**مهم:** لو المشروع متظبّط على `/` قبل كده، لازم تغيّرها لـ `dist` من
Settings ← Builds & deployments ← Build configurations.

## إزاي تنشر مقال جديد

1. `content/articles` ← **Add file** ← **Create new file**
2. اسم الملف بالإنجليزي وبنهاية `.md` — مثال: `salary-guide.md`
3. الصق القالب ده وعدّل عليه:

```
---
title: "عنوان المقال زي ما هيظهر في الصفحة"
meta_title: "العنوان اللي هيظهر في جوجل"
meta_description: "وصف قصير سطرين هيظهر تحت العنوان في جوجل"
date: 2026-09-10
draft: false
---

اكتب المقدمة هنا.

## عنوان فرعي

كلام عادي. **الكلام بين نجمتين بيطلع غامق.**

- نقطة
- نقطة تانية

| عمود | عمود |
|---|---|
| قيمة | قيمة |
```

4. **Commit changes**

المقال هيظهر تلقائيًا في `/blog/` وفي الصفحة الرئيسية وفي `sitemap.xml`.

- `draft: true` = المقال متحفوظ بس مش ظاهر على الموقع.
- التاريخ بيحدد الترتيب، الأحدث الأول.


## نشر مقال مكتوب بـ HTML

نفس الخطوات، بس اسم الملف بنهاية `.html` بدل `.md`.

```
---
title: "عنوان المقال"
meta_title: "العنوان في جوجل"
meta_description: "وصف سطرين"
date: 2026-09-10
draft: false
---

<p>اكتب أو الصق كود HTML عادي هنا.</p>

<h2>عنوان فرعي</h2>
<p>كلام مع <strong>غامق</strong> و<a href="/services/">لينك</a>.</p>

<ul><li>نقطة</li><li>نقطة تانية</li></ul>
```

**مهم:**
- الأسطر اللي بين `---` مطلوبة زي ما هي، حتى في ملف HTML.
- لو لزقت صفحة HTML كاملة فيها `<html>` و `<head>` و `<body>`،
  النظام هيشيلهم لوحده وياخد المحتوى بس.
- `<h1>` بيتشال تلقائيًا لأن عنوان الصفحة بيتطبع من `title`.
- أكواد `<script>` و `<style>` بتتشال لأسباب أمنية.
- استخدم `<h2>` و `<h3>` للعناوين الفرعية — دي اللي جوجل بيقراها.

## تعديل بيانات المكتب

كل حاجة في أول `build.mjs` جوه `SITE`: رقم الواتساب، رقم الرخصة،
الإيميل، العناوين، والدومين. غيّرها هناك وهي هتتغير في كل الصفحات.

## نموذج التواصل

النموذج في `/contact-us/` شغال دلوقتي بالواتساب: بيجمع بيانات الزائر
ويفتحله محادثة برسالة جاهزة.

**علشان يبعتلك إيميل بدل كده:**
1. ادخل web3forms.com واكتب إيميلك — هيبعتلك مفتاح (Access Key) مجاني
2. حط المفتاح في `SITE.formAccessKey` جوه `build.mjs`
3. Commit — النموذج هيبقى بيبعت إيميل لكل طلب

## Google Analytics

حط المعرّف (شكله `G-XXXXXXXXXX`) في `SITE.gaId` جوه `build.mjs`.
الكود هيتحط تلقائيًا في كل الصفحات.

## Google Search Console

1. ادخل search.google.com/search-console
2. ضيف الموقع واختار طريقة التحقق **HTML file**
3. نزّل ملف التحقق وارفعه في جذر المستودع (نفس مكان `build.mjs`)
4. ضيف اسم الملف في نهاية `build.mjs` علشان يتنسخ لـ `dist`، أو استخدم
   طريقة التحقق بالـ DNS من Cloudflare (أسهل ومش محتاجة ملف)
5. بعد التحقق، ابعتلهم `sitemap.xml`

## هيكل الملفات

```
build.mjs              مولّد الموقع — كل الصفحات بتتولد من هنا
assets/style.css       كل التصميم
partials/*.html        أقسام الصفحة الرئيسية
content/articles/*.md  المقالات
img/                   الصور
dist/                  الناتج (بيتولد تلقائيًا — متعدلش فيه)
```
